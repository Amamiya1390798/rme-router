# RME Router 使用手册

RME Router 用“谁的声音送到哪里”的方式，管理 MADIface XT、12Mic、OctaMic XTC 之间的路由。TotalMix FX 2.1 要在后台运行，实际的混音和路由仍由它完成；本 App 是更清楚的操作界面。

## 安装与打开

```bash
cd ~/rme/RMERouter && scripts/make-app.sh release --install
```

装好后在“应用程序”（你自己的 `~/Applications`）或启动台里打开 **RME Router**。第一次打开会出现设置向导。

## 第一次连接

1. **TotalMix**：Options 菜单勾选 OSC Control；Settings → OSC 选一个空闲的 Controller，勾 In Use，Port (incoming) 填 `7011`、Port (outgoing) 填 `9011`、Remote Host 填 `127.0.0.1`，Compatibility 选 **Global OSC**，关闭 Follow Submix。想看电平，再勾 **Send Level Data**。
2. **12Mic**：设备上 STATE → remote → HTTP Remote 打开。网线连接地址 `http://12mic.local`，USB 直连 `http://172.20.0.1`。
3. **XTC**（可选）：用 USB 接上 XTC，在“连接”页 XTC 一节选“从 XTC 收”和“发往 XTC”两个 MIDI 端点、设备 ID（XTC 面板 Options → General Settings），打开“读取 XTC”。要让本 App 改 XTC，先关掉 TotalMix 的 Aux Device 和 MIDI Remote 对 XTC 的控制，勾选确认，再打开“允许本 App 改动 XTC”。
4. 点工具栏右上的 **读取设备**（↻）。

## 各页面

| 页面 | 用来做什么 |
| --- | --- |
| 设备 | 三台设备的前后面板与实物线缆；点接口只看它自己的线和通道；下方是 XT 的通道条（同 TotalMix：选输出看送到它的电平；点一条输入画出它送到哪些输出和电脑录音第几路；拖来源到输出新建发送；奇数号通道上可合并 / 拆分立体声） |
| 输出 | 每个在用的输出现在送出什么。点来源看它的信号流；点电平改电平和声像；XT 输出可改静音、相位、音量、平衡；点“送一路声音”加发送；12Mic 的“直通”改来源 |
| 信号流 | 选一个通道，看它跨设备的完整去向与来源，每一段都有状态点 |
| 前级 | XT Mic 1–2、12Mic、XTC Mic 1–8 每一路的增益、48V、相位、标签；可以直接改（XTC 要先允许改动） |
| 时钟 | 各设备采样率、时钟源、各数字输入的 Lock/Sync |
| 体检 | 14 条规则检查哪里配置不对，带说明、改法、读不到时去哪看 |
| 场景 | 保存整套设置，之后对比、恢复 |
| 接线 | 设备之间实际接了哪些线；改了这里，其他页面立即跟着变 |
| 连接 | TotalMix 端口、12Mic 地址、XTC 的 MIDI 设置、确认方式、备份、重新打开向导 |

右上角工具栏：**跨设备送一路声音**（分叉图标）、**检查器**（右侧面板，显示选中通道的全部信息）、**读取设备**。

## 常用操作

- **看一路声音送到了哪里**：信号流页左边选通道；或在任何卡片上点通道名。
- **调发送电平**：输出页点卡片右侧的 dB 数，拖滑块，“加入待应用”。
- **声像**：同一个弹窗里还有“声像”滑块（左 100 … 中 … 右 100），只能改已经存在的发送。
- **通道条**：XT 输出卡标题下有一排按钮：静音、相位、音量、平衡；检查器里选中 XT 的输入、回放或输出也有“通道条”一节（输入、回放只有静音和相位）。立体声通道改一边就是改两边（相位除外，左右分开）。**快速方式下，输出音量一次抬高超过 20 dB 会弹确认框；取消静音、合并拆分直接发送。**
- **跨设备送一路声音**：工具栏分叉图标 → 选来源和去处（可勾“左右成对”）→ 计算路径。App 会列出每一步：自动（TotalMix 新建发送从 -30 dB 起步、12Mic 路由；允许改动 XTC 时还有 XTC 整块 8 路路由）、沿用已有、线缆、人工（没允许改动 XTC 时的 XTC 面板步骤）。人工步骤会出现在底部“需人工完成”清单里，做完勾掉。
- **这台 Mac**：设备页点“这台 Mac”，看 XT 怎么接的电脑、采样率、哪些程序（如 Logic）正在用它；可在这里改采样率（会确认，12Mic、XTC 要跟着改）。
- **控制室**：设备页“控制室”一栏：Dim、Main 单声道、全局静音一点就切；快照 1–8 点了调用（整套混音替换，一定会确认，不能撤销）。
- **和 TotalMix 同步**：在 TotalMix 里改了配对、名字、发送，App 一秒内跟上，不用再按“读取设备”。
- **核对接线**：设备页右上“信号核对…”，选一支麦克风、点开始、对着它说话。App 告诉你它实际进了 XT 的哪一路，和预期一致就把这根线记为已核对（线从虚线变实线）。需要 XT 在线并勾 Send Level Data。
- **虚线 / 问号的意思**：虚线的线、带“？”的来源，都还没被证实（只是接线表里写的，或设备没读到、用的是演示数据）。
- **麦克风进电脑**：硬件输入第 n 路就是电脑录音第 n 路，不用拉线；在 DAW 里选这个输入即可。
- **改前级**：前级页点增益数字调；点“48V 关 / 开”“Ø 正相 / 反相”切换。
- **改 12Mic 路由**：输出页 12Mic 卡片上点“直通”换来源；或点分栏标题旁“新建 12Mic 路由”。
- **场景**：场景页输入名字 → 保存；之后“对比”看差异，“恢复…”把差异加入待应用并打开确认框。读到 XTC 时，场景也存 XTC 的路由（按 8 路块）和前级；要恢复 XTC 部分，需先允许本 App 改动 XTC。来源是 ADAT IN、AES IN、电脑回放的块只能在 XTC 面板上恢复。
- **备份**：连接页“导出…”，换电脑后“导入…”。

## 改动是怎么发出去的

- **每次确认**（默认）：改动先进底部“待应用”栏 → 点“应用…” → 确认框列出要发送的原文、TotalMix 通道名 → “确认发送” → 回读核对，显示“已核对”或“回读不一致”。每一批都能“撤销这批…”。
- **快速**（连接页切换）：点下就发送并核对。**切换 48V、一次抬高超过 20 dB、恢复场景仍然会弹确认框；其余点下即发送。**
- 打开 48V 时，确认框里必须先勾选“没有接带式话筒等不能接幻象电源的设备”。
- XT 未连接时，写入只改 TotalMix 保存的配置，不会出声；接上 XT 后 TotalMix 会把它应用到声卡。

## 状态点

实心绿 = 从设备读到；空心黄 = 推断或只有文档依据；灰色虚线 = 未知（读不到，或演示数据）；红 = 有问题。

## 已知限制

- **XTC 只接受一个控制来源**：本 App、TotalMix Aux Device、MIDI Remote 同时只能用一个。不打开“读取 XTC”时本 App 不向 XTC 发任何消息。XTC 的时钟、采样率只读，要在面板上改。
- **XTC 增益**只有 0 dB 和 10–65 dB：本 App 限 0–60 dB，1–9 dB 会按 10 dB 发送。
- **XTC 还没接实物核对过**：协议按手册实现，USB MIDI 端点名、回包格式要等接上 XTC 再确认。
- **TotalMix 的 Global OSC 没有采样率和时钟源地址**：XT 的时钟需要在 TotalMix 的 Settings 里人工确认。
- **12Mic 没有读电平的接口**（手册未写），所以只有 XT 有电平表。
- **12Mic 没有密码保护**：网络上的任何人都能改它。本 App 读取时只发 null，写入只走确认流程。
- 设备接头类型（SC / SFP / BNC）是占位值，接线页可能提示“需要转接跳线”，按实物核对即可。
- TotalMix 里**隐藏的通道**读不到名字，也就无法在 App 里显示或修改；要用的通道不要隐藏。
- 版本 0.9.0：12Mic 真机、XT 在线状态、电平表还没有接实物核对过（见设计文档第 8.1 节阶段 C）。

## 排查

| 现象 | 处理 |
| --- | --- |
| “TotalMix 没有回应” | 检查 Global OSC 是否打开、端口是否与“连接”页一致；开着 Wi-Fi 时把 TotalMix 地址改成 `::1` 试试 |
| 12Mic 一直红点 | 检查网线 / USB、地址（`12mic.local` 或 `12mic.local.`、`172.20.0.1`）、HTTP Remote 是否打开 |
| 电平一直“无信号” | XT 是否在线；TotalMix OSC 设置里勾 Send Level Data |
| 某个通道显示“对照表为推断” | App 按 TotalMix 通道名推断它对应的接口；对照 TotalMix 屏幕确认一次即可 |
| XTC“没有回应” | 端点选对了吗（收、发各一个）；设备 ID 是否和 XTC 面板一致；XTC 面板 Options → MIDI Sources 是否允许 USB 控制 |
| 体检很多“无法判断” | 多半是设备没读到；先让三台设备都在线再看 |
