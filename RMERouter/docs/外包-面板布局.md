# 外包任务：三台设备前后面板的接口位置（给 GPT）

## 你要做的

1. 用手机正对拍 6 张照片：MADIface XT、12Mic、OctaMic XTC 各拍前面板、后面板。
   - 尽量正面、不斜；整块面板入镜；光线均匀。
2. 把 6 张照片和下面的提示词一起发给 GPT。
3. 把 GPT 回的 JSON 存成 `docs/panel-layout.json`，告诉我。我会校验后接进“设备”页。

## 提示词（整段复制）

```text
我会给你 6 张照片：RME MADIface XT、RME 12Mic、RME OctaMic XTC 的前面板和后面板。
请为每张照片输出这台设备这一面上所有接口的位置，只输出一个 JSON，不要解释。

规则：
- 坐标归一化：以面板外框为 0–1，x 从左到右，y 从上到下；给每个接口的中心 (x, y) 和大小 (w, h)。
- 只列接口（插头、插座、光口、网口、电源口、开关），不列按钮、旋钮、屏幕、LED、螺丝、文字。
- 每个接口给 "label"：照片上印的字，看不清写 null；不要猜。
- "type" 只能是以下之一：xlr_combo, xlr, trs, ts, bnc, sc_optical, sfp, toslink, dsub9, dsub25, din5, minidin, usb_a, usb_b, usb3, epcie, rj45, iec, dc, power_switch, other。
- 照片里看不全或被线挡住的接口也列出，加 "occluded": true。
- 拍得歪的照片，按面板外框四角校正后再给坐标，并在该面写 "skew_corrected": true。

输出格式：
{
  "xt":    {"front": [...], "rear": [...]},
  "12mic": {"front": [...], "rear": [...]},
  "xtc":   {"front": [...], "rear": [...]}
}
其中每一项：{"label": "MADI 1 IN", "type": "sc_optical", "x": 0.42, "y": 0.55, "w": 0.06, "h": 0.2, "occluded": false}
最后单独列出你不确定的接口（"uncertain": [...]），写明原因。
```

## 我这边怎么用

- 接口的种类和数量以手册为准（设计文档第 6.4.1 节）；照片只提供位置。
- 两者对不上时（比如照片多一个接口），App 里标“待核对”，不自动采用。
